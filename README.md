Welcome to the **Pizza Restaurant Website** project! This website is designed for showcasing your pizza restaurant online with a responsive design, user-friendly forms, and integration with **Google Maps** for location. It includes multiple pages like **Home**, **Contact**, **Blog**, **Franchise**, **Store**, and **Suggestions**.

## Features
- **Home Page:** Showcase your restaurant with a welcoming design.
- **Contact Page:** Form for users to send inquiries and feedback.
- **Blog Page:** Share updates and news about the restaurant.
- **Franchise Page:** Information about franchise opportunities.
- **Store Page:** Display your pizza menu and other items.
- **Suggestions Page:** Allow users to submit suggestions for improving the restaurant.
- **Google Maps Integration:** Easy location navigation for users to find your restaurant.

## Tech Stack
- **Frontend:** HTML, CSS
- **Google Maps Integration**
- **Responsive Design for all devices**

## How to Use the Website

### **For Regular Users:**
1. Visit the website URL (for example: [Pizza Restaurant](https://example.com)).
2. Browse through the **Home**, **Blog**, **Store**, and other pages.
3. Fill out the **Contact** or **Suggestions** form to get in touch or provide feedback.
4. Use the **Google Maps** integration to easily find the restaurant's location.

### **For Developers:**
1. Clone the repository:  
   ```bash
   git clone https://github.com/aayush61203/pizza-restaurant-website.git
   ```
2. Open the project folder:
   ```bash
   cd pizza-restaurant-website
   ```
3. You can now edit the **HTML** and **CSS** files to customize the website as needed.
4. If you want to test the website locally, open the **index.html** file in your browser.
